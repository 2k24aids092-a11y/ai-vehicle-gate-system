# Frontend - React + Vite

## Setup

```bash
cd frontend
npm install
cp .env.example .env.local
npm run dev
```

## Build

```bash
npm run build
```

## Structure

- `src/pages/` - Page components
- `src/components/` - Reusable components
- `src/services/` - API services
- `src/hooks/` - Custom React hooks
- `src/store/` - Zustand store
